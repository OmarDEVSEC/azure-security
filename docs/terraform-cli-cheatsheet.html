terraform cli cheat sheet

the commands you'll actually reach for during this project

core workflow --daily
terraform init

Downloads providers and sets up the working directory. Run once per project, and again any time you add a new provider or a new module.

terraform plan

Dry run — shows exactly what would be created, changed, or destroyed, without touching real infrastructure. Always run before apply.

terraform apply

Executes the plan against real infrastructure. Prompts for confirmation ("yes") unless run with -auto-approve.

Read the plan output before confirming — this is the step that actually costs money or breaks things.

terraform destroy

Tears down everything Terraform manages in the current state. Used between lab sessions to avoid ongoing cost.

Irreversible. Double check you're in the right directory/workspace first.

terraform validate

Checks syntax and internal consistency without touching Azure or generating a plan. Fast way to catch typos.

terraform fmt

Auto-formats .tf files — fixes spacing/alignment. Run before committing so diffs stay clean.

targeting & scoping --precision
terraform plan -target=module.monitoring

Limits the plan to one resource or module — useful for applying the monitoring module first, in isolation, before the rest of the lab.

Same -target flag works with apply and destroy too.

terraform apply -auto-approve

Skips the yes/no confirmation prompt. Useful in scripts or CI — riskier in normal use since there's no last look at the plan.

terraform plan -out=tfplan

Saves the exact plan to a file so a later apply uses precisely what you reviewed, rather than re-computing (and possibly drifting).

terraform apply tfplan

Applies a previously saved plan file instead of generating a new one.

inspecting state --introspection
terraform show

Prints the current state in human-readable form — every resource Terraform currently manages and its attributes.

terraform state list

Lists every resource address currently tracked in state, e.g. azurerm_resource_group.monitoring.

terraform state show <address>

Shows full detail for one specific resource by its state address.

terraform output

Prints all declared output values, e.g. the monitoring module's action_group_id.

terraform graph

Outputs the dependency graph in DOT format — pipe into Graphviz to visualize how resources depend on each other.

version & setup --environment
terraform -version

Prints the installed Terraform version and any out-of-date warning.

terraform providers

Lists every provider required by the current configuration and where each is used.

terraform workspace list

Lists available workspaces (isolated state environments) — useful later if you split dev/prod-style lab environments.

related azure cli --auth
az login

Authenticates the CLI (and by extension, the azurerm provider) against your Azure account.

az login --tenant <tenant-id>

Authenticates against a specific tenant when your account has access to more than one.

az account show

Shows the currently active subscription — confirm state is "Enabled" before running Terraform.

az account list --output table

Lists every subscription your account can see, in a readable table format.
